# SEO Monitor

A production-ready system to monitor SEO health of multiple websites with Telegram alerts and a dashboard.

## Features

- 🔍 **SEO Scanning**: Check meta titles, descriptions, H1 tags, links, images, and more
- 📊 **Dashboard**: Real-time visualization of SEO metrics
- 🤖 **Telegram Alerts**: Get notified immediately when issues are found
- 🗄️ **Scalable**: Handles 1200+ sites with Celery workers
- 📈 **Trend Analysis**: Track SEO score over time
- 🚀 **Docker Ready**: Easy deployment with Docker Compose
